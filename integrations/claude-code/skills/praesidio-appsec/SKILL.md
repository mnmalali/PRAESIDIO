# PRAESIDIO application security

Confirm the owned or expressly authorized target, allowed methods, test accounts, rate limits, and data handling. Map routes, authentication states, API inputs, and privilege boundaries before active testing. Use source-aware analysis when source exists; use dynamic probes only within scope.

Strix, Shannon, PentAGI, PentestGPT, Nuclei, and similar tools are optional external engines. Run only an installed, pinned version with a reviewed license and explicit target scope. Do not assume a catalog entry means PRAESIDIO installed or executed that tool. Keep proof of concept tests minimal, reversible, and free of third-party data.

Report exact request or code path, expected versus observed behavior, impact, reproduction, and remediation. Mark unvalidated leads as such.
