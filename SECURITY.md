# Security policy

Report vulnerabilities in PRAESIDIO privately through GitHub's **Report a vulnerability** feature for this repository. Include a minimal reproduction, affected commit, deployment configuration, and impact. Remove API keys, personal data, and raw private prompts from the report.

The repository's backend, SDKs, dashboard, website, and maintained integrations are in scope. Only test systems you own or have explicit permission to assess. Do not test third-party hosted services under this policy.

Security reports are reviewed by the repository maintainers. No response time, bounty, or hosted-service coverage is promised.
