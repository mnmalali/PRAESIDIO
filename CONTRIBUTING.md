# Contributing to PRAESIDIO AI

Keep changes narrow, preserve working security behavior, and include meaningful validation. Read AGENTS.md and the canonical project wiki before implementation. Document modified upstream files and retain original notices.

Contributions to this derivative are under Apache-2.0 unless explicitly agreed otherwise. No contributor license agreement is required. Original contributor history is preserved in CONTRIBUTORS.md. Do not submit code, publish packages, or send user data to third-party services on this project's behalf.

Run the appropriate Go, SDK, dashboard and website checks in docs/praesidio/RELEASE_REPORT.md. Do not commit secrets, databases, model weights or raw customer traces.
