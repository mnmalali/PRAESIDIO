# PRAESIDIO AI public website

Independent Next.js marketing project. It requires Node 22 or later and npm, with no Go, GPU, database, Docker, private credentials or sibling-source imports.

The homepage, navigation, footer, setup guide, and About page link to the [PRAESIDIO GitHub repository](https://github.com/mnmalali/PRAESIDIO).

```sh
npm ci
npm run lint
npm run typecheck
npm run build
npm start
```

Open http://127.0.0.1:3001. For development use `npm run dev`.

Routes: `/`, `/product`, `/security`, `/docs`, `/changelog`, `/about`, `/contact`. Unknown routes return 404. All three demo scenarios run entirely in the browser and are prominently labelled **SIMULATED DEMO**. No security verdict is generated by a real model here, and no action is executed or transmitted.

`NEXT_PUBLIC_SITE_URL` is the only environment setting. Set it to the verified HTTPS public origin before the production build. Without it, robots are disabled and the sitemap is empty. Do not put passwords, agent API keys or model credentials in any `NEXT_PUBLIC_*` variable. The contact page intentionally has no invented address or unconnected form.

For Vercel set Root Directory to `website`, Framework to Next.js, install command `npm ci`, build command `npm run build`, and use the framework's default output directory. Keep preview deployments unindexed. See [deployment notes](../docs/praesidio/VERCEL_DEPLOY.md).

The authenticated console is the separate `frontend/` project. Its optional `PRAESIDIO_API_URL` server setting points to a separately hosted Go backend; the public site does not proxy or connect to it.

The website uses the user's supplied PRAESIDIO shield, original product illustrations and copy, and locally served Geist Sans/Mono fonts. Font licensing is retained in [geist-OFL.txt](public/licenses/geist-OFL.txt). No reference-site assets or remote font requests are used. [Apache-2.0 license](public/LICENSE.txt); [upstream attribution](../UPSTREAM_ATTRIBUTION.md).

The shield responds to pointer tilt and click/Enter. On supported desktop browsers, a native CSS scroll timeline carries it between page gutters. Mobile and unsupported browsers use a static position; system reduced-motion preferences and the header pause control disable movement. Workflow choices and the three demo scenarios support native radio keyboard navigation. See [redesign evidence](../docs/praesidio/WEBSITE_REDESIGN.md).
