# Skill sources
Last updated: 2026-11-19

The repository's `.agents/skills/` now contains only five original PRAESIDIO security skills: agent-security, ai-redteam, appsec, audit, and runtime. These are mirrored in the Claude Code plugin. The design and UI skills used during website development were removed from the repository; the old installer scripts that could restore them were also removed. Historical website design credits remain in the About page. No third-party security skill pack is bundled; see [SECURITY_ECOSYSTEM.md](SECURITY_ECOSYSTEM.md) for the external source catalog.
